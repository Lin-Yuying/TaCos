TaCos · Markdown 语法速查

项目 Overview 与说明文档使用的全部语法，以及 Notion 风格的输入快捷键。

在 Overview 里，你不需要先写 Markdown 再预览：输入的标记会立刻变成对应的样式， 语法符号在光标移开后自动隐藏。把光标移回文字里，符号会重新出现，方便修改。

用 / 打开命令菜单。 在任何空行输入 /，可以选标题、列表、待办、引用、代码块、分割线， 也可以用方向键选择后回车。记不住语法时，这是最快的入口。

输入即转换

输入 变成
# + 空格 一级标题（## 二级，### 三级）
- + 空格 圆点列表（* + 空格、+ + 空格 同样有效）
1. + 空格 有序列表，回车后自动接着编号
[] + 空格 待办事项；也可以用 - [ ] + 空格
> + 空格 引用块
``` + 空格 代码输入框（先写语言，例如 ```js + 空格，可获得 JS 代码块）
--- 分割线

如果标记没有自动转换，把光标放到行首按 Enter 也可以完成转换： - 会变成列表，``` 会变成代码块。

键盘操作

按键 作用
Tab 缩进当前行（列表整体缩进一级；代码块内为选中的每一行加两个空格）
Shift + Tab 减少缩进，把嵌套的列表或代码行退一级
Enter 新建一段；在列表里继续下一项；在空列表项上按一次退回上一级，再按一次结束列表
Shift + Enter 在同一段内换行（代码块内直接按 Enter 换行）
⌘/Ctrl + B 加粗选中的文字
⌘/Ctrl + I 斜体
⌘/Ctrl + E 行内代码
⌘/Ctrl + Enter 结束当前块的编辑
↑ / ↓ 在行首或行尾继续按，会跳到上一块或下一块
拖拽 / ⌘+A ×2 跨块选择；选中后可整体删除、复制或缩进
Backspace / Delete 删除选中的块
Esc 取消选择或结束编辑

点击任意一块即可编辑；点击文档末尾的空白处，会像 Notion 一样在最后新起一行。 编辑内容会自动保存，右上角出现 Saved 表示已经写入。

行内格式

写法 效果
**粗体** 粗体
*斜体* 或 _斜体_ 斜体
~~删除线~~ 删除线
`行内代码` 行内代码
[文字](https://example.com) 链接（只允许 http、https、mailto）
<https://example.com> 自动链接

列表嵌套

在列表项上按 Tab 会嵌套到上一项的下一级，按 Shift + Tab 退回。最多四级。回车新建的下一项会沿用当前层级；在空列表项上回车， 会先退一级，退到最外层再回车就结束列表。

代码块

输入 ``` 再按空格，会得到一个带边框的代码输入框。代码块里的 Tab 给选中的行加两个空格，Shift + Tab 去掉它们； Enter 是普通换行，不会拆成新的文档块。

保存

Overview 的修改会自动保存，不需要按钮。离开页面时尚未发出的写入也会立即补上， 所以直接关窗口不会丢失最后一次编辑。
